# holdout 运行登记

每次在 holdout 上跑评测都要追加一行，包括失败、中断和误触发的运行。
每个 holdout 版本单独起一段。段内第一行是该版本唯一的「正式报数运行」，其后的行必须标注为「该版本已失效」，
数值不得再作为最终结论对外使用（规则见 `PROTOCOL.md` §4）。

空表本身也是证据：说明到目前为止没有任何参数是在 holdout 上选的。
