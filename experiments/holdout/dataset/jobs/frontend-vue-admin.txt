岗位：前端开发工程师（Vue 中后台）
地点：深圳
性质：全职

岗位职责
1. 负责中后台管理系统的页面、组件和交互逻辑开发，与后端完成接口联调。
2. 基于 Vue 3 + TypeScript 搭建和维护业务模块，持续提高组件复用率。
3. 参与状态管理、路由、构建配置和前端性能优化。
4. 完善加载、错误、空状态与多端适配体验。

任职要求
1. 熟悉 Vue 3、TypeScript、JavaScript、HTML、CSS。
2. 熟悉 Pinia 或 Vuex、Vue Router，并能使用 Vite 等构建工具。
3. 有通用组件抽象、数据可视化或复杂表单开发经验。
4. 了解首屏资源、懒加载、分包等常见性能优化方式。
