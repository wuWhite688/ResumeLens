岗位：Java 后端开发工程师（订单履约）
地点：深圳
性质：全职

岗位职责
1. 负责订单、库存、履约等服务的接口开发与维护，参与需求拆解和技术方案评审。
2. 处理高并发下的重复请求、状态一致性、异步消息与失败补偿问题。
3. 参与数据库表结构、索引和慢 SQL 优化，并完善日志、监控和自动化测试。
4. 与前端、测试及上下游服务协作，保障关键链路可回溯、可恢复。

任职要求
1. Java 基础扎实，熟悉 Spring Boot、MyBatis 或同类 ORM 框架。
2. 熟悉 MySQL 的事务、索引和常见 SQL 优化方法。
3. 熟悉 Redis 的缓存、分布式锁或幂等类场景。
4. 使用过 Kafka、RocketMQ、RabbitMQ 中至少一种消息队列，理解重复消费和可靠投递问题。
5. 有订单、支付、库存或履约类项目经历者优先。
