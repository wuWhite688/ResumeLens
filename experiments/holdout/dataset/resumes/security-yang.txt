校园与非专业经历

专业技能
- 熟悉 SOC 日常流程，能够处理安全告警研判、事件分级和处置跟踪。
- 使用 Splunk SIEM 查询终端、网络和身份日志，编写基础检测规则。
- 使用 EDR 调查进程树、文件哈希和主机行为，提取 IOC 并协助隔离受影响终端。
- 熟悉 MITRE ATT&CK 常见战术与技术，可用于映射检测覆盖和复盘攻击链。
- 了解 WAF、IDS/IPS、DNS、HTTP(S)、Windows 事件日志和 Active Directory 基础。
- 使用 Python 编写日志清洗和告警富化脚本。

工作实践
安全告警降噪
梳理一批高频误报规则，根据资产类型、账号属性和已知运维行为增加上下文条件。上线前先回放历史日志评估漏报风险，再逐步调整阈值。规则调整后保留变更记录，便于回溯。

事件响应演练
参与钓鱼邮件导致终端执行异常脚本的演练。通过 SIEM 关联登录与网络日志，在 EDR 中回看进程链，提取域名和文件哈希，按流程隔离测试主机并更新封禁列表。复盘时按 MITRE ATT&CK 标注关键步骤，补充相应检测用例。

说明
日常工作以授权范围内的防御、检测和响应为主，不进行未经授权的攻击测试。

校园与课程
参加过学校信息安全协会的公开讲座组织工作，负责报名、签到和资料归档。课程作业涉及密码学基础、网络协议分析和安全管理制度，但均在教学环境中完成，不计入真实事件响应案例。

其他实践
曾为学院实验室整理资产清单和借用记录，发现信息不一致时与管理员核对。参与志愿服务时负责人员登记与场地巡查，这些经历主要体现流程执行，不与 SOC 专业能力混淆。

工作习惯
处理告警时保留时间线和原始证据，不因为单一特征就直接下结论。对敏感数据按最小必要原则使用，公开复盘会做脱敏。英语可阅读常见厂商知识库。业余兴趣是羽毛球和纪录片，与安全岗位技能无直接关系。
