职位名称：Java 后端开发工程师（支付中台）
公司：汇通支付科技
地点：杭州
用工：全职

岗位描述
我们正在建设统一支付中台，覆盖商户进件、下单、渠道路由、回调验签、退款与 T+1 对账。希望候选人能独立负责一条支付链路，而不是只做单表 CRUD。
日常工作包括：用 Spring Boot 提供稳定的 REST API；治理 MySQL 慢查询；用 Redis 做幂等与限流；用 Kafka 把支付结果异步分发给账单和风控。需要能看懂渠道文档，处理签名失败、重复回调和金额不一致。
团队实行值班制，线上超时与对账失败需要能在日志里定位到具体商户和渠道流水号。

任职要求
1. 本科及以上，计算机相关，3 年及以上 Java 后端经验。
2. 精通 Java，熟悉并发、线程池与常见线上问题排查。
3. 熟练使用 Spring Boot、Spring MVC、MyBatis 或 JPA。
4. 熟悉 MySQL 索引与事务，有过慢 SQL 优化案例。
5. 熟悉 Redis（缓存、分布式锁）以及 Kafka 或同等消息队列。
6. 有支付、交易、清结算或对账系统经验优先。
7. 能使用 Docker 与 Linux 完成基本部署与排障。
8. 重视接口幂等、超时与补偿，能把边界情况写成测试。
