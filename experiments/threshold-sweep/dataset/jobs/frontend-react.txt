职位名称：前端开发工程师（React）
公司：视界互动
地点：上海
用工：全职

岗位描述
负责 B 端增长与投放工作台的前端建设。产品形态以中后台为主：复杂表格、权限点、多步表单、实时状态与暗色主题。
你需要使用 React 与 TypeScript 交付可维护页面，参与内部组件库，推动性能（LCP / INP）和可访问性，而不是只还原视觉稿。
与设计共同维护 Token，与后端约定接口分页、错误码与空态。构建工具以 Vite 为主，仓库是 monorepo。

任职要求
1. 本科及以上，3 年及以上前端经验。
2. 精通 JavaScript / TypeScript，理解异步、模块化与类型约束。
3. 熟练使用 React 18、Hooks、React Router；有 Next.js 经验加分。
4. 熟悉至少一种状态方案：Redux Toolkit、Zustand 或 React Query。
5. 能独立完成构建优化：代码分割、包体积分析、路由懒加载。
6. 有组件库或 Design System 经验优先，了解 Storybook。
7. 关注无障碍与性能指标，能用数据说明一次重构是否有效。
8. 能与设计、后端协作，书面表达接口契约与交互边界。
