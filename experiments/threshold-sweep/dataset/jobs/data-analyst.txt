职位名称：数据分析师（会员与促销）
公司：橙湾零售
地点：深圳
用工：全职

岗位描述
服务零售会员与促销运营，把活动效果讲清楚：谁来了、谁下单、谁退款、钱花得值不值。
工作包括用 SQL 取数、用 Tableau / Excel 做看板、用 Python 做周报自动化，以及协助 A/B 实验的样本量与口径。
你需要先对齐指标定义，再给结论。我们不需要只会导出一张大表、让业务自己看的人。

任职要求
1. 本科及以上，统计学、数学、经济或相关专业，2 年及以上业务分析经验。
2. 精通 SQL，能写窗口函数、留存、漏斗与分层查询。
3. 熟悉 Excel 与至少一种可视化工具（Tableau / Power BI）。
4. 会用 Python Pandas 做清洗和重复性报表自动化。
5. 了解 A/B 实验基础，能指出偷看与样本量不足的风险。
6. 能撰写口径文档，与数仓、运营对齐「订单」「活跃」「核销」定义。
7. 零售、会员或增长分析经验优先。
